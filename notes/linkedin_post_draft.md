## DRAFT B — Lead with the science

A neural network learned the physics of a reaction-diffusion system. Then I let
it run forever on its own output.

The problem: it kept locking into the same patterns. Strong attractors. Always
worms, always swirls. Beautiful, but stuck.

The fix: give every cell its own parameter values from a slowly drifting spatial
field. Now different regions live in different regimes simultaneously. The system
can never lock into one attractor because no two regions are ever in exactly the
same state.

[VIDEO]

9 seconds. No resets. Pure autonomous evolution from a 17,000-parameter model
trained on Gray-Scott reaction-diffusion physics.

The technique is simple. The result is something I haven't seen before.

Code + paper notes: github.com/kosmickroma/somnivex
